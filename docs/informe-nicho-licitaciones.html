Metodología (planeada) y limitaciones ya conocidas

  • Esta API no soporta búsqueda por texto libre (a diferencia de q en Compra Ágil): el filtrado por palabra clave es local sobre el listado completo de cada estado consultado, no una búsqueda del servidor.
  • Sin acotar por fecha, un estado con volumen país completo puede ser demasiado grande para barrer de forma confiable en una sola corrida — el script avisa en consola si detecta ese caso (ver informe-nicho.ts).
  • Los nombres de campo (MontoEstimado, Garantia.*, etc.) están tomados de documentación pública histórica, sin confirmar contra una respuesta real todavía.
